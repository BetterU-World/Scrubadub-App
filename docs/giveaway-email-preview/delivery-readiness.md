## Address privacy and postal validity

Use a protected **server-only** environment secret named `SCRUB_CAMPAIGN_POSTAL_ADDRESS` (proposed, not created), scoped to the production email runtime and accessible only to authorized operators. Never use a `VITE_` variable, client bundle, committed `.env`, public template constant, browser query parameter, fixture, screenshot, exception payload, or general log. A future renderer must read the value only in the outgoing-message path, reject a missing/blank value, HTML-escape it for HTML and insert the same address into plain text. Public/offline preview generation must never read this secret, even when it exists. Privately review the final footer in an authorized inbox; no screenshots or render dumps containing the real address should be committed. The received email necessarily discloses the address to recipients; secrecy applies to configuration and public artifacts, not the required delivered footer.

The [FTC compliance guide](https://www.ftc.gov/business-guidance/resources/can-spam-act-compliance-guide-business) permits a current valid street postal address, USPS-registered PO box, or properly registered private mailbox. Formatting alone does not prove postal validity, current sponsor use, or receipt of mail. Do not send the private address to a public geocoder/search. Founder must privately confirm that it is current, complete, deliverable, legitimately used by the sponsor, and suitable for publication in participant emails; authorized private postal validation is needed if uncertain. **CAN-SPAM address compliance is not yet verified.** A statement that an address will be used does not securely configure it.

Marketing email requires clear opt-out handling. Keep it operational for at least 30 days after sending and honor requests within the FTC's 10-business-day maximum; this campaign should suppress immediately. No login, payment, or multi-step process. See the FTC guide for message-purpose and advertising disclosure rules. Winner content contains an optional software promotion; do not assume all winner content is categorically exempt. Confirm its treatment before sending, or apply the same private-footer/opt-out safeguards while keeping prize claims independent of marketing preferences.

# Operations Assessment Growth Roadmap v1

Roadmap version 1 is a deterministic Convex transformation of the frozen report. It is stored separately as `roadmapSnapshot`, preserving the immutable PR3 report.

Rules declare stable IDs, version, section, materiality, dependency, branch applicability, deduplication key, and mutual-exclusion group. Eligible report opportunities are ordered by materiality and stable finding ID. Foundational high-impact items without prerequisites enter Now (maximum two); dependent and remaining priorities enter Next, then Later. The fixed dependency graph places scheduling before quality/team and financial visibility before growth. The graph is acyclic and no Now item depends on a later stage.

Each item freezes its finding reference, section, internal evidence, dependency metadata, bilingual current/target states, rationale, 2–4 practical actions, observable success indicators, sequencing language, and optional secondary SCRUB compatibility. Public components do not render internal IDs, priorities, dependencies, or evidence.

Limited Confidence selects at most two improvement priorities, omits Maintain, and uses cautious language. Moderate Confidence uses measured language. High Confidence is direct. Early maturity guidance begins by documenting minimum standards and ownership. Ready-to-Scale and Operationally Advanced guidance adds leading indicators and delegated review.

Maintain is generated only from supported report Strengths and converts praise into a preservation habit. Solo operators never receive Team Communication items. Empty stages remain visible with an honest sparse-state explanation.

Repeated generation returns the original roadmap and timestamp. Capability validation, completed status, and an existing frozen report are required. PR5 retains conversion, continuity, saved accounts, delivery, sharing, and follow-up behavior.
